# Presente de aniversário — Victória

Site estático pronto para GitHub Pages.

## Arquivos

- `index.html` — conteúdo e estrutura
- `style.css` — visual e responsividade
- `script.js` — animações, galeria e revelação final
- `images/` — fotos usadas no site

## Publicar no GitHub Pages

1. Substitua os arquivos atuais do repositório pelos arquivos desta pasta.
2. Envie também a pasta `images` inteira.
3. No GitHub, abra `Settings` → `Pages`.
4. Em `Build and deployment`, deixe `Deploy from a branch` e selecione a branch principal (`main`) e `/root`.
5. Aguarde alguns minutos e atualize o endereço do site.

## Presente final

O botão final leva somente ao link do curso na Kiwify. Nenhum login ou senha foi incluído no código.
